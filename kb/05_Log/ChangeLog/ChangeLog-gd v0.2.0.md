# ChangeLog-gd v0.2.0

`docs/CHANGELOG.md`（v0.2.0 节）。2026-10-05。由 v0.1.7 加 0.1。

外链不再弹出倒计时遮罩。点中的按钮轮廓跑两圈光，大约 2 秒后打开目标；光的颜色跟按钮相近。普通文字链接用白色光。按钮高亮时文字颜色不变。

主站空列表用 [[gd-empty-state]]：标题「暂无结果」加说明，不放放大镜。列表一页 12 张，用 [[gd-pager]]。友链卡 320×100，描述一行，悬停看全文。页脚是主站首页、帮助文档、关于本站、友情链接、联系站长。
