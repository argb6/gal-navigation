# 项目概述

## Summary

GALNAVI（example.com）是 ACG 二次元资源聚合导航站，基于 Cloudflare Workers + D1 + KV 构建，所有页面为单文件 Worker。

## Definition

| 属性 | 值 |
|------|-----|
| 域名 | example.com |
| 技术栈 | Cloudflare Workers + D1 + KV |
| 组件库 | gd（GalNavi Design），对齐 MD3 语义 |
| 视觉风格 | 深色玻璃拟态 |
| 页面数 | 9（index / websearch / palace / about / help / friend / donate / status / error） |

## 升级阶段

| Phase | 内容 | 状态 |
|-------|------|------|
| Phase 1 | gd 组件库 + MD3 对齐 | ✓ 完成 |
| Phase 2 | 图片懒加载 | ✓ 完成 |
| Phase 3 | 项目知识库 | 持续进行 |
| Phase 4 | 网页重构 + 新人友好 | 进行中 |
| Phase 5 | 开源代码 | 待启动 |

## 当前版本

- gd 组件库：v1.3.0
- 核心组件：14 类
- Token 数量：168+
