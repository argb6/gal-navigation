# 状态层模式

> [!abstract] Summary
> 所有交互组件使用 MD3 状态层透明度，通过 `::before` 伪元素叠加实现 hover/focus/pressed/disabled。

## Definition

| Token | 值 | MD3 状态 |
|-------|-----|---------|
| `--gd-state-hover` | `0.08` | Hover |
| `--gd-state-focus` | `0.12` | Focus |
| `--gd-state-pressed` | `0.12` | Pressed |
| `--gd-state-disabled` | `0.38` | Disabled |

## Implementation

```css
.gd-button::before {
  content: "";
  position: absolute;
  inset: 0;
  background: currentColor;
  opacity: 0;
  pointer-events: none;
}
.gd-button:hover::before   { opacity: var(--gd-state-hover); }
.gd-button:focus-visible::before { opacity: var(--gd-state-focus); }
.gd-button:active::before   { opacity: var(--gd-state-pressed); }
.gd-button:disabled { opacity: var(--gd-state-disabled); pointer-events: none; }
```

## 红线

- **禁止垂直位移**：`translateY(-1px)` 禁止，用 `filter: brightness(1.06)`（卡片 hover 为 `1.05`）
- NSFW 开关另用 `.is-on` / `.is-flash`，不是状态层透明度
- **焦点环**：所有交互元素必须 `outline: 2px solid var(--gd-color-primary); outline-offset: 2px`
- **prefers-reduced-motion**：关闭所有 transition 和 transform
