# D1 数据库

## Summary

Cloudflare D1（SQLite）存储导航站点、友链和殿堂分组数据。

## Definition

| 绑定名 | 用途 | 使用者 |
|--------|------|--------|
| `DB` | 主站导航 + 友链 | 主站 / 详情 / 关于 / 友链 |
| `GROUP_DB` | 殿堂分组 | 殿堂 |

## 数据表

### 站点导航表（sites）

| 字段 | 类型 | 说明 |
|------|------|------|
| `item_key` | TEXT PK | 站点唯一标识 |
| `title` | TEXT | 站点名称 |
| `category` | TEXT | 分类（simulators / websites / tools / company / hanhua） |
| `tags` | TEXT | 逗号分隔标签 |
| `short_desc` | TEXT | 简短描述 |
| `url` | TEXT | 站点链接 |
| `icon_path` | TEXT | 图标路径 |
| `md_content` | TEXT | 详情页 Markdown 内容 |
| `updated_at` | TEXT | 最后更新时间 |

### 友链表（friends）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 自增 ID |
| `name` | TEXT | 站点名称 |
| `url` | TEXT | 站点链接 |
| `des` | TEXT | 站点描述 |
| `favicon_url` | TEXT | 图标 URL |
| `catalog` | TEXT | 分类 |
| `update_tm` | TEXT | 更新时间 |

### 殿堂资源表（resources）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 自增 ID |
| `category` | TEXT | 分组分类 |
| `name` | TEXT | 资源名称 |
| `url` | TEXT | 资源链接 |

## SQL 查询示例

```js
// 全量站点查询
await env.DB.prepare(
  "SELECT item_key, title, category, tags, short_desc, url, icon_path, updated_at FROM sites ORDER BY category ASC"
).all();

// 单站点详情
await env.DB.prepare(
  "SELECT title, short_desc, tags, md_content, category FROM sites WHERE item_key = ?"
).bind(itemKey).all();

// 友链查询
await env.DB.prepare(
  "SELECT id, name, url, des, favicon_url, catalog FROM friends"
).all();

// 友链提交
await env.DB.prepare(
  "INSERT INTO friends (name, url, des, favicon_url, catalog, update_tm) VALUES (?, ?, ?, ?, ?, datetime('now'))"
).bind(name, url, description, "", catalog).run();

// 殿堂数据
await env.GROUP_DB.prepare(
  "SELECT * FROM resources ORDER BY category, id"
).all();

// 状态页站点列表
await env.DB.prepare(
  "SELECT item_key, title, url FROM sites WHERE url IS NOT NULL AND url != '' LIMIT 40"
).all();
```
