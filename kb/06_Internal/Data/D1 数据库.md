# D1 数据库

> [!abstract] Summary
> Cloudflare D1（SQLite）存储导航站点、友链和殿堂分组数据。表名以 Worker 实际 SQL 为准。

## Definition

| 绑定名 | 用途 | 使用者 |
|--------|------|--------|
| `DB` | 主站导航 + 友链 | 主站 / 详情 / 关于 / 友链 |
| `GROUP_DB` | 殿堂分组 | 殿堂 |

## 数据表

### 站点导航表（navi_sites）

| 字段 | 类型 | 说明 |
|------|------|------|
| `item_key` | TEXT PK | 站点唯一标识 |
| `title` | TEXT | 站点名称 |
| `category` | TEXT | 分类（simulators / websites / tools / company / hanhua） |
| `tags` | TEXT | 逗号分隔标签 |
| `short_desc` | TEXT | 简短描述 |
| `url` | TEXT | 站点链接 |
| `icon_path` | TEXT | 图标 URL（Cloudflare R2） |
| `md_content` | TEXT | 详情页 Markdown 内容 |
| `is_active` | INTEGER | `1` 正常；`2` NSFW；`0` 下架 |
| `updated_at` | TEXT | 最后更新时间 |

> [!warning] 表名
> 主站/详情/状态查的是 `navi_sites`，不是 `sites`。

### 友链表（sites）

友链 Worker（`friend.js`）当前查询：

```sql
SELECT id, name, url, des, favicon_url, catalog FROM sites
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 自增 ID |
| `name` | TEXT | 站点名称 |
| `url` | TEXT | 站点链接 |
| `des` | TEXT | 站点描述 |
| `favicon_url` | TEXT | 图标 URL |
| `catalog` | TEXT | 分类 |
| `update_tm` | TEXT | 更新时间（写入时用） |

> [!info] 与 ADR
> ADR-0003 设计名是 `friends`。现网页查 `sites`。以 Worker SQL 为准。

### 殿堂资源表（resources）

绑定 `GROUP_DB`（`group1`）。Worker：`SELECT * FROM resources ORDER BY category, id`。页面用到的列：

| 字段 | 说明 |
|------|------|
| `id` | 序号 |
| `category` | 分组 |
| `name` | 游戏名 |
| `official_url` | 官网 |
| `details_url` | 详情 |
| `link1` / `link2` / `link3` | 外链 |

> [!warning] 不是只有 url
> 旧笔记只写了 `id, category, name, url`。现网页没有用 `url` 这一列，用的是 `official_url` / `details_url` / `link1–3`。AI 不得直接改 D1。

## SQL 查询示例

```js
// 全量站点查询
await env.DB.prepare(
  "SELECT item_key, title, category, tags, short_desc, url, icon_path, updated_at, is_active FROM navi_sites WHERE is_active IN (1, 2) ORDER BY category ASC"
).all();

// 单站点详情
await env.DB.prepare(
  "SELECT title, short_desc, tags, md_content, category, is_active FROM navi_sites WHERE item_key = ?"
).bind(itemKey).all();

// 友链查询（friend.js 实际表名）
await env.DB.prepare(
  "SELECT id, name, url, des, favicon_url, catalog FROM sites"
).all();

// 友链提交
await env.DB.prepare(
  "INSERT INTO sites (name, url, des, favicon_url, catalog, update_tm) VALUES (?, ?, ?, ?, ?, datetime('now'))"
).bind(name, url, description, "", catalog).run();

// 殿堂数据
await env.GROUP_DB.prepare(
  "SELECT * FROM resources ORDER BY category, id"
).all();

// 状态页站点列表
await env.DB.prepare(
  "SELECT item_key, title, url FROM navi_sites WHERE url IS NOT NULL AND url != '' AND is_active = 1 LIMIT 40"
).all();
```
