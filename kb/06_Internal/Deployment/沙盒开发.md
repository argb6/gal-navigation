# 沙盒开发

## Summary

各页面独立沙盒环境，通过 `serve.mjs` 启动本地 HTTP 服务器，模拟 Cloudflare 绑定。

## Definition

| 端口 | 页面 | 启动命令 |
|------|------|----------|
| 8100 | galnavi 首页 | `node sandbox/galnavi-sandbox/serve.mjs` |
| 8300 | help | `node sandbox/help-sandbox/serve.mjs` |
| 8301 | about | `node sandbox/about-sandbox/serve.mjs` |
| 8302 | friend | `node sandbox/friend-sandbox/serve.mjs` |
| 8303 | detail | `node sandbox/detail-sandbox/serve.mjs` |
| 8304 | status | `node sandbox/status-sandbox/serve.mjs` |
| 8804 | donate | `node sandbox/donate-sandbox/serve.mjs` |

## 构建式沙盒

donate 使用构建脚本：

```bash
node sandbox/donate-sandbox/build-donate.mjs          # 沙盒版（含 DEMO）
node sandbox/donate-sandbox/build-donate.mjs --deploy # 部署版（读 KV）
```

## 冻结存档

`*-freeze/` 目录存放冻结版本（最终成品），仅供备份参考，不随构建更新。

## 文件位置

- 沙盒目录：`sandbox/`
- 冻结存档：`sandbox/*-freeze/`
