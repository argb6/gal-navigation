# 沙盒开发

> [!abstract] Summary
> 沙盒把 `worker/new` 的页面副本跑在本地 Node HTTP 上，模拟 D1/KV。改页面先改 `sandbox/*-sandbox/`，确认后再同步正式 Worker。

## 统一入口

日常用这一条：

```bash
node sandbox/serve.mjs
```

默认 **http://127.0.0.1:8100**。改过 `*.js` 后必须重启，ES 模块在进程启动时加载。

| 路径 | 页面 |
|------|------|
| `/` | 发布页 |
| `/nav/` | 主站 |
| `/nav/palace/` | 圣器殿堂 |
| `/nav/about/` | 关于 |
| `/nav/help/` | 帮助 |
| `/nav/friend/` | 友链 |
| `/nav/donate/` | 捐献 |
| `/nav/detail/?item_key=site-alpha` | 详情（mock） |
| `/status/` | 状态 |

实现：`sandbox/lib/sandbox-server.mjs` 动态 `import` 各页 Worker，把 HTML 里的站点 origin 换成沙盒地址。Mock 数据在 `sandbox/lib/mock-data.mjs`。

## 分端口入口

各页仍可单独起服务（`sandbox/<page>-sandbox/serve.mjs`）：

| 端口 | 页面 |
|------|------|
| 8100 | index |
| 8101 | palace |
| 8102 | websearch |
| 8300 | help |
| 8301 | about |
| 8302 | friend |
| 8303 | detail |
| 8304 | status |
| 8804 | donate |

> [!warning] 不要改生产副本冒充预览
> 沙盒目录是预览源。`worker/new/*.js` 是部署源。两边未同步时，以沙盒实验、生产未变为准。

## 2026-08-31 沙盒行为

相对当时的 `worker/new` 副本，沙盒已做这些：

- 去掉 Cookie 读写与年龄门，见 [[Decision-沙盒去 Cookie 与年龄门]]
- `.gd-groundback` 用 `100vw × 100dvh` 铺满窗口，`html { overflow-x: hidden }` 避免滚动条缝（详情页同样锁横向滚动）
- 关于 / 帮助 / 友链 / 捐献：页脚 `position: fixed; bottom: 0`；标题和横向虚线靠左；侧栏靠右。间距用 px，不用 `vw`，缩放时相对位置不漂
- 殿堂搜索中：隐藏分类导航，结果按 神器 → 仙器 → 魔器 分组
- 主站卡片：`grid-template-columns: repeat(auto-fill, minmax(min(100%, 300px), 1fr))`，左右固定 32px（窄屏 16px）

## 文件位置

- 统一服务：`sandbox/serve.mjs`
- 共享：`sandbox/lib/sandbox-server.mjs`、`sandbox/lib/mock-data.mjs`
- 页面副本：`sandbox/<name>-sandbox/<name>.js`
