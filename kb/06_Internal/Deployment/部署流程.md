# 部署流程

> [!abstract] Summary
> 每个 Worker 对应 `wrangler/<name>.toml`，通过 Wrangler CLI 部署到 Cloudflare Edge。

## Definition

```bash
# 部署单个 Worker
npx wrangler deploy -c wrangler/<name>.toml

# 或使用 npm scripts
npm run deploy:websearch
npm run deploy:palace
# ... 等
```

## toml 配置结构

```toml
name = "websearch"
main = "../worker/new/websearch.js"    # 路径相对 toml 所在目录
compatibility_date = "2026-08-01"

[[d1_databases]]
binding = "DB"
database_name = "nav"
database_id = "YOUR_D1_DATABASE_ID"

[[kv_namespaces]]
binding = "CAROUSEL_KV"
id = "YOUR_KV_NAMESPACE_ID"
```

## 绑定对照

| Worker | D1 绑定 | KV 绑定 | Service Binding |
|--------|---------|---------|-----------------|
| 主站 | `DB` | `CAROUSEL_KV` `FEATURED_KV` | — |
| 关于 | `DB` | — | — |
| 详情 | `DB` | — | — |
| 殿堂 | `GROUP_DB` | — | — |
| 友链 | `DB` | — | — |
| 捐献 | — | `DONATE_KV` | — |
| 状态 | `DB` | `STATUS_KV` `NOTICE_KV` | — |
| 404 | — | `STATUS_KV` | 全部 Worker |

## 环境变量

- `CF_API_TOKEN` — 目标是 Secret 绑定。`worker/new/status.js` 目前仍是页内常量，开源前必须改掉并轮换
- `.wrangler/` — 账号凭证缓存（已 gitignore）
