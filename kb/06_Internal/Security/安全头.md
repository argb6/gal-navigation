# 安全头

> [!abstract] Summary
> 所有页面 Worker 共享安全头基线，CSP 只可收紧不可放宽。

## Definition

```js
const SECURITY_HEADERS = {
  "Content-Type": "text/html; charset=utf-8",
  "Cache-Control": "private, no-store",
  "X-Content-Type-Options": "nosniff",
  "X-Frame-Options": "SAMEORIGIN",
  "Referrer-Policy": "strict-origin-when-cross-origin",
  "Content-Security-Policy": "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; img-src 'self' data: https:; connect-src 'self'; font-src 'self' data: https://fonts.gstatic.com; frame-ancestors 'self'; base-uri 'self'; form-action 'self'",
};
```

## CSP 指令说明

| 指令 | 值 | 原因 |
|------|-----|------|
| `script-src` | `'self' 'unsafe-inline'` | JS 全内联（部分页另允许 Cloudflare Insights） |
| `style-src` | `'self' 'unsafe-inline' https://fonts.googleapis.com` | CSS 全内联 + Google Fonts 样式表 |
| `img-src` | `'self' data: https:` | Cloudflare R2 图标（`assets.galnavi.top`）+ data URI SVG |
| `font-src` | `'self' data: https://fonts.gstatic.com` | 系统字体 + Noto Sans SC / Outfit |
| `connect-src` | `'self'` | 仅同源（/nav/api/*）；部分页另允许 `https://galnavi.top` |

## 规则

- 各页只能**收紧** CSP，不能放宽
- `worker/shared/security.js` 提供基线 + 合并工具
- 当前各页仍用页内副本（未 import shared 版本）

## 文件位置

- 基线：`worker/shared/security.js`
- 各页副本：`worker/new/*.js`（SECURITY_HEADERS 常量）
