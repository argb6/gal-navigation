# 玻璃表面系统

> [!abstract] Summary
> GALNAVI 视觉核心：三级玻璃分层（无模糊卡片 / 模糊浮层 / 强玻璃顶栏），数值冻结禁止修改。线条图案的 `filter: blur` 不算卡片玻璃。

## Definition

| Class | 背景 | 模糊 | 用途 |
|-------|------|------|------|
| `.gd-glass` | `rgba(18,22,40,0.42)` | 无 | 卡片、内容表面 |
| `.gd-glass--blur` | `rgba(18,22,40,0.42)` | `blur(18px) saturate(165%)` | 浮层、弹窗 |
| `.gd-glass--strong` | `rgba(8,12,24,0.75)` | `blur(20px) saturate(180%)` | 导航栏 |

## 红线

- 卡片类**禁止** `backdrop-filter` / `box-shadow`
- 只有弹窗/遮罩/导航栏可用 `backdrop-filter` 类 blur
- 玻璃数值**冻结**，禁止借「整理」之名改 blur/透明度

> [!info] 装饰线条不是 backdrop-filter
> 页面背景和殿堂条目卡用 R2 线条图，在 `::before` / `::after` 上写 `filter: blur(10.8px)` + `mix-blend-mode: screen`。这是模糊图案本身，不是把背后内容糊掉。与卡片红线不冲突。见 [[gd-groundback]]。

## 遮罩层级

```css
--gd-color-overlay: rgba(navy-deep, 0.88);         /* 弹窗背景 */
--gd-color-overlay-strong: rgba(navy-panel, 0.92);  /* 重定向弹窗 */
--gd-color-overlay-float: rgba(navy, 0.95);          /* 抽屉背景 */
```
