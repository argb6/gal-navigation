# 数据流

> [!abstract] Summary
> GALNAVI 有三条数据路径：B-SSR、B-JSON、B-REST。静态图片走 [[Cloudflare R2]]，不经过这三条路径。

## Definition

| 路径 | 模式 | 说明 |
|------|------|------|
| B-SSR | Worker 查 D1/KV → 拼 HTML → 返回 | detail / friend / palace |
| B-JSON | Worker 注入 JSON 到 `<script>` → 客户端渲染 | websearch（NAV_DATA / HERO_IMAGES / FEATURED_KEYS） |
| B-REST | 独立 API Worker → D1 CRUD | d1-rest.js（管理操作） |

## Architecture

```
D1/KV
  ↓ 查询
Worker（fetch handler）
  ↓ safeJson() 序列化
HTML 字符串（CSS 内联 + JS 内联 + 数据注入）
  ↓ Response
浏览器
  ↓ class 匹配
gd 组件渲染
```

## Implementation

### B-JSON 路径（websearch.js）

1. Worker 端：`fetchNavData(env)` 查 D1，`fetchHeroImages(env)` 读 KV
2. 序列化：`safeJson()` 转义 `</` 防 XSS
3. 注入：`var NAV_DATA = ${dataJson};`
4. 客户端：JS 读全局变量，DOM 操作渲染卡片

### KV 数据注入

```js
const dataJson = safeJson(navData);
const heroJson = safeJson(heroImages);
const featJson = safeJson(featuredKeys);
```
