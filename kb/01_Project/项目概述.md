# 项目概述

> [!abstract] Summary
> GALNAVI（galnavi.top）是 ACG 二次元资源聚合导航站。边缘上跑 10 个单文件 Worker，界面用自研 gd 组件库（深色玻璃拟态）。

## Definition

| 属性 | 值 |
|------|-----|
| 产品 | 收录与检索 ACG 相关站点、工具、模拟器等资源 |
| 域名 | galnavi.top |
| 运行形态 | 每页一个 Cloudflare Worker；HTML / CSS / JS 全内联 |
| 数据 | D1（`nav` 导航、`friend` 友链、`group1` 殿堂）+ KV（轮播、推荐、捐款、状态、公告）+ R2（图标与品牌图） |
| 界面 | gd（GalNavi Design）v1.5.2；对齐 MD3 语义，不换玻璃拟态皮 |
| 页面 | 10 个，见下表 |

和 [[Cloudflare Worker]] 同属 `01_Project`：本篇讲站点是什么、仓库怎么摆；那篇讲 Workers 运行时和源码模块边界。页面怎么拼 HTML、怎么绑数据，见 [[Worker 架构]]、[[数据流]]。

## 页面

| 页面 | Worker | 做什么 |
|------|--------|--------|
| 首页 | `index.js` | 入口落地 |
| 主站导航 | `websearch.js` | 检索收录站点；轮播与推荐 |
| 详情 | `detail.js` | 单条站点说明（Markdown） |
| 圣器殿堂 | `palace.js` | 分组资源 |
| 关于 | `about.js` | 站点说明 |
| 帮助 | `help.js` | 使用说明 |
| 友链 | `friend.js` | 友链表与提交 |
| 捐献 | `donate.js` | 捐款名单 |
| 状态 | `status.js` | 站点可用性与公告 |
| 404 | `error.js` | 未匹配路径兜底，并按 sitemap 转发到对应 Worker |

## 仓库布局

| 路径 | 用途 |
|------|------|
| `worker/new/` | 现网页面 Worker（零 `import`） |
| `worker/shared/` | 常量 / 安全 / SEO 的对照源，现网页不引用 |
| `worker/share/` | `robots.txt`、`sitemap.xml` |
| `src/` | gd 组件库（只跑在浏览器侧字符串里） |
| `wrangler/` | 现网部署 toml（GitHub 仓没有） |
| `sandbox/` | 本地预览（GitHub 仓没有） |
| `source/` | `worker/new` 的阅读副本（十页齐全；密钥已掏空，勿部署） |
| `docs/` | 入口 `docs/README.md`；规范 `docs/standard/` |
| `kb/GALNAVI-KB/` | 工程知识库，入口 `README.md` |

静态图走公开域 `https://assets.galnavi.top/`（R2）。接口密钥 / 账密 / token 不写进知识库，走环境变量或 Wrangler Secret。
