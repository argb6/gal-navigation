# 存储

> [!abstract] Summary
> 结构化行在 D1，小 JSON 在 KV，图片文件在 R2。绑定名以现网 toml 和 Worker SQL 为准（与 GitHub `worker/layer/database/` 一致）。

AI 只许帮写查询，不许直接改库。

## 怎么分

| 存哪 | 存什么 |
|------|--------|
| D1 | 导航站点、友链、殿堂分组 |
| KV | 轮播 URL、推荐 key、捐款名单、监控状态、公告 |
| R2 | favicon / 站点图标 / logo 等文件 |

旧笔记把 KV 写成 `CAROUSEL_KV` / `carousel_images`、殿堂写成 `GROUP_DB`，那是脱敏名。现网和 GitHub layer 用下面这套。

## D1

| 绑定（`env.`） | 库名 | 谁用 |
|----------------|------|------|
| `DB` | `nav` | 主站、详情 |
| `DB` | `friend` | 友链 Worker。绑定名仍是 `DB`，库名是 `friend`，表 `sites` |
| `group1` | `group1` | 殿堂。不是 `GROUP_DB` |

关于页 toml **没有** D1。状态页代码能查 `env.DB`，现网 `status.toml` 没绑，用页内兜底清单。

### navi_sites

主站 / 详情 /（可选）状态。不是友链表 `sites`。

| 字段 | 说明 |
|------|------|
| `item_key` | 主键 |
| `title` `category` `tags` `short_desc` `url` | 列表展示 |
| `icon_path` | 图标 URL（R2） |
| `md_content` | 详情 Markdown |
| `is_active` | `1` 正常；`2` NSFW；`0` 下架 |
| `updated_at` | 更新时间 |

`category` 原始键：`simulators` / `websites` / `tools` / `company` / `hanhua`。

### sites（友链）

在 D1 库 `friend` 上，不在 `nav`。

```sql
SELECT id, name, url, des, favicon_url, catalog FROM sites
INSERT INTO sites (name, url, des, favicon_url, catalog, update_tm) VALUES (?, ?, ?, ?, ?, datetime('now'))
```

ADR 里的设计名 `friends` 现网没用。

### resources（殿堂）

`env.group1`：`SELECT * FROM resources ORDER BY category, id`。页面用 `official_url` / `details_url` / `link1–3`，没有单独的 `url` 列。

### 查询对照

```js
env.DB.prepare(
  "SELECT item_key, title, category, tags, short_desc, url, icon_path, updated_at, is_active FROM navi_sites WHERE is_active IN (1, 2) ORDER BY category ASC"
).all();

env.DB.prepare(
  "SELECT title, short_desc, tags, md_content, category, is_active FROM navi_sites WHERE item_key = ?"
).bind(itemKey).all();

env.group1.prepare("SELECT * FROM resources ORDER BY category, id").all();
```

GitHub：`worker/layer/database/d1.js`。

## KV

| 绑定 | Key | 内容 | 谁用 |
|------|-----|------|------|
| `HERO_KV` | `hero_images` | JSON 字符串数组 | 主站 |
| `FEATURED_KV` | `featured_items` | JSON key 数组 | 主站 |
| `DONATE_KV` | `donors` | `{name,amount,note,date}[]` | 捐献 |
| `STATUS_KV` | `state` | 监控 JSON | 状态 |
| `STATUS_KV` | `api_cache` | CF API 缓存 | 状态 |
| `NOTICE_KV` | `notice` | 纯文本 | 状态 |

读列表失败：`JSON.parse` → 按逗号拆 → `[]`。GitHub：`worker/layer/database/kv.js`。

```bash
npx wrangler kv key put --binding=HERO_KV "hero_images" '["https://example.com/a.webp"]' -c wrangler/websearch.toml
```

## R2

公开域 `https://assets.galnavi.top/`。浏览器直接读，不经 Worker 代发。

| 对象 | 用途 |
|------|------|
| `/favicon.png` | favicon |
| `/icon.png` | apple-touch-icon、OG |
| `/logo.png` | 顶栏 / 发布卡 |

`navi_sites.icon_path` 存各站图标的完整 URL。原先 Supabase 桶已弃。CSP `img-src` 含 `https:`。

## 不要写进本篇

接口密钥、账密、`CF_API_TOKEN` 明文。状态页调 Cloudflare API 应走 Secret。
