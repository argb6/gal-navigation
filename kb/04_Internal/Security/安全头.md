# 安全头

> [!abstract] Summary
> 各页只能收紧 CSP，不能放宽。现网是页内 `SECURITY_HEADERS` 副本；GitHub 另有 `worker/layer/security/`，入口同样还没 import。

## 基线

```js
const SECURITY_HEADERS = {
  "Content-Type": "text/html; charset=utf-8",
  "Cache-Control": "private, no-store",
  "X-Content-Type-Options": "nosniff",
  "X-Frame-Options": "SAMEORIGIN",
  "Referrer-Policy": "strict-origin-when-cross-origin",
  "Content-Security-Policy": "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; img-src 'self' data: https:; connect-src 'self'; font-src 'self' data: https://fonts.gstatic.com; frame-ancestors 'self'; base-uri 'self'; form-action 'self'",
};
```

对照源：`worker/shared/security.js`。本仓 `worker/*.js` 不 import。

| 指令 | 值 | 原因 |
|------|-----|------|
| `script-src` | `'self' 'unsafe-inline'` | JS 内联；部分页另加 Cloudflare Insights |
| `style-src` | `'self' 'unsafe-inline' https://fonts.googleapis.com` | CSS 内联 + Google Fonts |
| `img-src` | `'self' data: https:` | R2 与 data URI |
| `font-src` | `'self' data: https://fonts.gstatic.com` | Noto / Outfit |
| `connect-src` | `'self'`，部分页加 `https://galnavi.top`；status 另加 `https://api.cloudflare.com` | `/nav/api/*`、同源拉取、状态页 CF API |

GitHub layer：`headers.js` / `escape.js` / `cookie.js` / `cors.js` / `verify.js`。不要把转义函数打进浏览器包。
