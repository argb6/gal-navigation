# 部署流程

> [!abstract] Summary
> 现网每个页面一份 `wrangler/<name>.toml`，`main` 指向 `worker/new`。GitHub `gal-navigation` 没有 wrangler 目录，不能拿它当部署说明书。

## 命令

```bash
npx wrangler deploy -c wrangler/<name>.toml
npm run deploy:galnavi     # index
npm run deploy:websearch
npm run deploy:detail
npm run deploy:palace
npm run deploy:about
npm run deploy:help
npm run deploy:friend
npm run deploy:donate
npm run deploy:status
npm run deploy:error
```

首页 Worker 名是 `index`，脚本是 `deploy:galnavi`。路由在 Cloudflare 控制台管，toml 里不写 routes，且 `workers_dev = false`。

## toml

`main` 相对 toml 所在目录。绑定名必须和 `env.xxx` 一致。

```toml
name = "websearch"
main = "../worker/new/websearch.js"
compatibility_date = "2025-01-01"
workers_dev = false

[[d1_databases]]
binding = "DB"
database_name = "nav"
database_id = "YOUR_D1_DATABASE_ID"

[[kv_namespaces]]
binding = "HERO_KV"
id = "YOUR_KV_NAMESPACE_ID"
```

开源或贴配置时换成占位符，不要提交真实 ID。`.wrangler/` 已 gitignore。

## 现网绑定

| Worker | toml | D1 | KV | Service |
|--------|------|----|----|---------|
| index | `galnavi.toml` | — | — | — |
| websearch | `websearch.toml` | `DB` | `HERO_KV` `FEATURED_KV` | — |
| detail | `detail.toml` | `DB` | — | — |
| palace | `palace.toml` | `group1` | — | — |
| friend | `friend.toml` | `DB` | — | — |
| donate | `donate.toml` | — | `DONATE_KV` | — |
| status | `status.toml` | — | `STATUS_KV` `NOTICE_KV` | — |
| about / help | 对应 toml | — | — | — |
| error | `error.toml` | — | — | index、websearch、detail、about、help、palace、donate、friend（**无 status**） |

## 密钥

`CF_API_TOKEN` 应走 Secret。`worker/new/status.js` 若仍是页内常量，开源前要拿掉并轮换。不要把 token 写进仓库。
