# 部署流程

> [!abstract] Summary
> 现网每个页面一份 `wrangler/<name>.toml`，`main` 指向 `worker/new`。GitHub `gal-navigation` 没有 wrangler 目录，不能拿它当部署说明书。

## 命令

```bash
npx wrangler deploy -c wrangler/<name>.toml
npm run deploy:galnavi     # index
npm run deploy:websearch
npm run deploy:detail
npm run deploy:palace
npm run deploy:about
npm run deploy:help
npm run deploy:friend
npm run deploy:donate
npm run deploy:status
npm run deploy:error
```

首页 Worker 名是 `index`，脚本是 `deploy:galnavi`。路由在 Cloudflare 控制台管，toml 里不写 routes，且 `workers_dev = false`、`keep_vars = true`。部署日志里的 `No targets deployed` 表示没改 Workers.dev / 路由目标，**脚本仍已 Uploaded**。

| detail | `detail.toml` | `DB` | — | — |

| friend | `friend.toml` | `DB` → 库 `friend` | — | — |
| donate | `donate.toml` | — | `DONATE_KV` | — |

| error | `error.toml` | — | — | index、websearch、detail、about、help、palace、donate、friend（**无 status**） |

## 密钥

只写用法，不写明文。`CF_API_TOKEN` 用 `npx wrangler secret put CF_API_TOKEN -c wrangler/status.toml`。`worker/new/status.js` 若仍有页内常量，阅读副本 `source/status.js` 已掏空，现网应改 Secret 并轮换。
