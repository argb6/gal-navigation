# 沙盒开发

> [!abstract] Summary
> 只有本仓库有沙盒。GitHub `gal-navigation` 没有 `sandbox/`。本地用 Node 跑 `worker/new` 的页面副本，mock D1/KV。

## 用法

```bash
node sandbox/serve.mjs
```

http://127.0.0.1:8100。改过页面 `*.js` 必须重启（ESM 启动时加载）。

| 路径 | 页面 |
|------|------|
| `/` | 发布页 |
| `/nav/` | 主站 |
| `/nav/palace/` `/about/` `/help/` `/friend/` `/donate/` | 对应页 |
| `/nav/detail/?item_key=site-alpha` | 详情 mock |
| `/status/` | 状态 |

`sandbox/lib/sandbox-server.mjs` 动态 import 各页，把 HTML 里的站点 origin 换成沙盒。Mock 在 `sandbox/lib/mock-data.mjs`。

各页也可单独起：`sandbox/<page>-sandbox/serve.mjs`（8100 index、8101 palace、8102 websearch、8300 help、8301 about、8302 friend、8303 detail、8304 status、8804 donate）。

> [!warning]
> 沙盒是预览源，`worker/new` 是部署源。沙盒可以 `import` `worker/shared/`；现网页不可以。Cookie / 年龄门已卸，见 [[Decision-沙盒去 Cookie 与年龄门]]。

## 文件

- `sandbox/serve.mjs`
- `sandbox/lib/sandbox-server.mjs`、`sandbox/lib/mock-data.mjs`
- `sandbox/<name>-sandbox/<name>.js`
